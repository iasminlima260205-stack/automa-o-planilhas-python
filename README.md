 # Automação de Planilhas - Relatório de Vendas

 Projeto em Python que lê uma planilha de vendas, limpa os dados, calcula o total e gera gráfico e relatório em Excel automaticamente.

 ## O que o projeto faz 
 - Lê o arquivo 'vendas.csv'
 - Limpa os nomes das cidades
 - Calcula o total vendido
 - Agrupa as vendas por cidade ( somando, sem sobrepor)
 - Gera um gráfico de barras por cidade
 - Exporta o relatório em Excel
'relatório_vendas.xlsx'

## Bibliotecas usadas 
- pandas
- matplotlib
- openpyxl

## Como rodar

Python codigo.py
